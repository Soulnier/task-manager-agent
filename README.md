# Task Manager Agent

Консольный ИИ-агент для управления личными и учебными задачами.

## Для чего нужен агент

Агент позволяет работать с задачами и файлами через запросы на обычном языке:

- добавлять задачи с низким, средним или высоким приоритетом;
- просматривать задачи с фильтром по статусу;
- просматривать и читать файлы в рабочей папке;
- создавать и перезаписывать текстовые файлы после подтверждения пользователя.

Например: «Добавь задачу подготовить отчёт с высоким приоритетом» или «Прочитай README.md и кратко перескажи его».

Языковая модель выбирает нужный инструмент, программа выполняет его и возвращает результат модели для формирования ответа. Задачи сохраняются в JSON-файле и доступны после перезапуска.

## Используемый стек

| Технология | Назначение |
|---|---|
| Python 3.10+ | Логика приложения и агентный цикл |
| OpenRouter | Доступ к языковым моделям через API |
| `openai` | Python-клиент для запросов к OpenAI-совместимому API |
| `python-dotenv` | Загрузка настроек и API-ключа из `.env` |
| JSON | Хранение задач в `agent/workspace/tasks.json` |
| Git и GitHub | Контроль версий и хранение исходного кода |

## Архитектура

Точка входа — `agent/agent.py`. Управление контекстом, хранение сессий и поиск вынесены в модули `context.py`, `sessions.py` и `docs_search.py`.

| Компонент | Назначение |
|---|---|
| `main` | Консольный диалог, подключение к API и история сообщений |
| `run_agent` | Цикл обращения к модели и обработки вызовов инструментов |
| `TOOLS` и `TOOL_FUNCTIONS` | Описания инструментов для модели и соответствующие Python-функции |
| `execute_tool` | Разбор аргументов, выполнение функций и обработка ошибок |
| Файловые инструменты | Просмотр, чтение и запись файлов с проверкой границ песочницы |
| Инструменты задач | Добавление, проверка и чтение задач из JSON |

Модель получает запрос и историю диалога. Если для ответа нужны данные или действие, она возвращает вызов инструмента. Программа выполняет его, добавляет результат в историю и снова обращается к модели. Цикл заканчивается итоговым ответом либо достижением лимита шагов.

История диалога сохраняется в `agent/sessions/<id>.json`, задачи — в `agent/workspace/tasks.json`, настройки подключения — в `agent/.env`.

## ЛР №3: контекст и память

В PowerShell из корня проекта (если окружение ещё не создано):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r agent/requirements.txt
if (!(Test-Path agent/.env)) { Copy-Item agent/.env.example agent/.env }
```

Заполните `OPENROUTER_API_KEY` в `agent/.env`. Затем:

```powershell
.\.venv\Scripts\python.exe agent/agent.py --session study --strategy summarize --budget 6000
```

Введите «Меня зовут Тимур, моя цель — подготовить защиту», выйдите через `/exit`
и запустите ту же команду. Спросите «Как меня зовут и какая у меня цель?».
Файлы диалогов в Git не попадают. Для независимого диалога укажите другой ID.
Второй режим — `--strategy trim`: он отбрасывает старые ходы целиком.
В `summarize` перед удалением выполняется отдельный запрос модели без инструментов.

Например: «Найди в документации приоритет по умолчанию и добавь две задачи».
`search_docs` ищет по трём документам в `agent/workspace/docs/`.
На запись задач требуется подтверждение. Эксперименты и команды воспроизведения:
[agent/LAB3.md](agent/LAB3.md).
