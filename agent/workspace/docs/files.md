# Файлы и подтверждение

Файловые инструменты работают внутри workspace. Для просмотра списка есть list_files, для чтения текста UTF-8 — read_file.

Запись через write_file требует подтверждения в терминале: введите y. Enter или n отменяют запись. Такое же подтверждение нужно при добавлении задачи.

Лимит размера текстового файла — 50 000 байт.
