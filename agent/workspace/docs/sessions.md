# Сессии и история

Для продолжения диалога после выхода используйте прежнее значение --session. Разные идентификаторы соответствуют разным диалогам.

Стратегия trim отбрасывает старые ходы целиком. Стратегия summarize пытается сохранить факты в краткой памяти. Параметр --budget ограничивает оценку входа.

Команда /exit завершает программу. Список задач общий для сессий этого проекта.
