# Задачи и приоритет

Приоритет по умолчанию — mid (средний). Для срочной задачи укажите high, для менее важной — low. Новая задача получает статус todo.

Для добавления используйте add_task. Просмотр списка выполняет list_tasks: all — все задачи, todo — незавершённые, done — выполненные.

Задачи сохраняются в workspace/tasks.json и доступны после перезапуска.
